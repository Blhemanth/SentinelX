2. Step-by-Step Cold Startup Sequence (T-30 Minutes)

Pre-Stage Staging: Execute this sequence exactly 30 minutes before taking the stage. Never launch services during the opening slide!

Step 1: Check Windows Camera Privacy Permissions
Open Windows Settings > Privacy & Security > Camera. Confirm: (1) Camera access is ON; (2) "Let desktop apps access your camera" is ON. Ensure Zoom, Teams, or Skype are fully exited and not holding a DirectShow device lock.

Step 2: Start MongoDB Database Service
Open PowerShell as Administrator: 

net start MongoDB
# Verify active connection:
mongosh --eval "db.adminCommand('ping')"

Step 3: Reset & Seed Database to Known Clean State

cd B:\SentinelX\backend
node src/scripts/seed.js
# Output must show: Default users created, cameras registered, clean incident history.

Step 4: Launch Express Backend API Service
Open dedicated Terminal 1: 

cd B:\SentinelX\backend
npm start
# Verify output: [Server] Listening on port 5000, MongoDB Connected.

Step 5: Launch React Operations Web Portal
Open dedicated Terminal 2: 

cd B:\SentinelX\frontend
npm run dev
# Verify output: VITE v5.x ready in 280 ms -> Local: http://localhost:5173/
Open Google Chrome to http://localhost:5173, login with operator credentials, and arrange browser window on the right half of the display screen.

Step 6: Launch Native Flutter Desktop Client
Open dedicated Terminal 3: 

cd B:\SentinelX
flutter run -d windows --release
# Alternatively launch pre-built executable:
# .\build\windows\x64\runner\Release\sentinelx.exe
Position Flutter application on the left half of the display screen. Confirm camera feed appears immediately.

4. Comprehensive Failure Diagnosis & Rapid Recovery Runbook

Live Troubleshooting Matrix Emergency Fixes
Failure Symptom Root Cause Immediate Recovery Procedure (< 10 Seconds)
Camera preview shows black screen or 0 FPS DirectShow video capture device locked by another Windows process. 1. In Flutter app, press Ctrl+R or click the top-right 'Reset Camera' icon.
2. If unresolved, run in PowerShell: Stop-Process -Name "sentinelx", verify no other apps use camera, and relaunch.
3. Speaker Line: "The DirectShow driver is re-synchronizing camera capture; let us examine the verified 10-minute telemetry baseline."
Flutter App crashes on launch Missing onnxruntime.dll in application directory or PATH. 1. Confirm onnxruntime.dll exists in b:\SentinelX\windows\flutter\ephemeral or system PATH.
2. Launch the pre-tested backup executable in docs/mernova/backup_bin/sentinelx.exe.
React Web Portal shows 'Disconnected' banner Express API server terminated or port 5000 blocked. 1. Check Terminal 1. If crashed, press Up Arrow + Enter to restart npm start.
2. Hard-refresh browser with Ctrl+F5.
Inference latency exceeds 3,000 ms Windows power throttling or background virus scan consuming CPU cores. 1. Verify AC adapter is firmly plugged into laptop.
2. Temporarily pause Windows Security real-time protection during presentation.
