SLIDE 6 // Edge AI: Native ONNX Runtime & Background Isolates

PresenterPresenter 2
Time Window1:55 – 2:20 (25 Seconds)
Slide TitleIsolate-Driven Native ONNX C-FFI Execution
Slide Text • The Problem: Synchronous native inference takes ~1,680 ms on CPU, locking the UI and causing severe application freeze.
• The Solution: OnnxInferenceWorker spawned on an isolated Dart background thread using Microsoft ONNX Runtime C-FFI.
• Temporal Tensor Construction: Ring buffer builds [1, 16, 3, 224, 224] Float32 tensor ($9.63 ext{ MB}$) transferred via SendPort in 5.0 ms.
• Strict Memory Hygiene: 25-cycle lifecycle validation shows zero leak plateauing with net drift of $-6.79 ext{ MB}$.
Recommended Visual Thread isolation diagram showing Main UI Thread (smooth 60 Hz vsync) communicating asynchronously with Worker Isolate (ONNX AVX2 execution).
Main TakeawayThe application maintains fluid 60 Hz responsiveness regardless of model latency, eliminating operator distraction.
Verbal Transition"Now, let's see SentinelX running live on actual hardware. Over to Presenter 3 for the live demonstration."
