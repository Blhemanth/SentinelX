It consists of a local MongoDB database, an authenticated Node.js Express REST API, an administrative React 19 + Vite web dashboard, an on-device Flutter Windows Desktop edge workstation, an embedded ONNX Runtime C-FFI inference engine, and an optional Python FastAPI / PyTorch ML microservice.

3. Environment Configuration (.env)

3.1 Backend Configuration (backend/.env)

The Express backend requires a configuration file named .env located inside backend/. If it does not exist, copy it from backend/.env.example:

Copy-Item backend\.env.example backend\.env
Variable Name Example Value Purpose & Security Rules
PORT 3000 Port where Express listens. Default 3000 matches Flutter client defaults.
NODE_ENV development Set to development for local testing, production for deployments.
MONGODB_URI mongodb://localhost:27017/sentinelx Connection string for MongoDB Community or MongoDB Atlas cluster.
JWT_ACCESS_SECRET 64-char Hex String Cryptographic secret used to sign short-lived (15m) access tokens.
JWT_REFRESH_SECRET 64-char Hex String Cryptographic secret used to sign long-lived (7d) HttpOnly refresh cookies.
CLIENT_ORIGINS http://localhost:5173,... Comma-separated list of web origins allowed by Express CORS middleware.
ML_SERVICE_URL http://localhost:8000 URL of the Python FastAPI microservice (if running).
INTERNAL_SERVICE_KEY 32+ char Secret HMAC Protocol v2 shared secret for trusted internal server communications.
ADMIN_EMAIL admin@sentinelx.local Default administrator account seeded on first database boot.
ADMIN_PASSWORD ChangeMe!2024 Default password seeded for bootstrap administrative access.
Generating Secure JWT Secrets: Run this command in PowerShell to generate cryptographically random 64-character hex strings: 
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

3.2 Frontend Configuration (frontend/.env)

The React web application automatically connects to http://localhost:3000 by default. To override it, create frontend/.env with: VITE_API_URL=http://localhost:3000.

7. Common Windows Errors & Troubleshooting

1. Port 3000 or 5173 Already in Use (EADDRINUSE)
Fix: Run in PowerShell: $c = Get-NetTCPConnection -LocalPort 3000 -ErrorAction SilentlyContinue; if ($c) { Stop-Process -Id $c.OwningProcess -Force }

2. MongoDB Connection Failed (ECONNREFUSED 127.0.0.1:27017)
Fix: Run in Administrator PowerShell: net start MongoDB

3. Missing onnxruntime.dll in Flutter Windows
Fix: Copy the DLLs from root to the runner build directory: 

Copy-Item onnxruntime.dll build\windows\x64\runner\Debug\
Copy-Item onnxruntime_providers_shared.dll build\windows\x64\runner\Debug\

4. Camera Permission Denied or Black Screen
Fix: Open Windows Settings > Privacy & Security > Camera. Turn ON "Camera access" and "Let desktop apps access your camera". Close any open Zoom or Teams calls.

5. Browser CORS Blocked Error
Fix: Ensure backend/.env has CLIENT_ORIGINS=http://localhost:5173,http://127.0.0.1:5173,http://localhost:3000 and restart the backend.

6. Flutter Device Not Detected (No supported devices)
Fix: Run: flutter config --enable-windows-desktop, then run flutter doctor.

9. Architecture Explained: How It All Works Together

SentinelX bridges the gap between hardware cameras and real-time security response:

  • MongoDB: The Memory Vault. Stores user credentials, incident logs, and audit trails.
  • Express API: The Security Gatekeeper. Enforces JWT auth, rate limits, and Protocol v2 HMAC.
  • React 19 Web: The Operations Window. Allows dispatchers to review alerts and acknowledge incidents.
  • Flutter Desktop: The Edge Workstation. Captures raw webcam frames at 7.33 FPS into a 16-frame circular queue.
  • ONNX Runtime: The On-Device Turbo Engine. Evaluates the 34M-parameter model on CPU AVX2 in ~1.35 seconds without freezing the UI (97.5% fluidity).
  • Python ML: The Laboratory. Prepares datasets, trains checkpoints, and provides microservice inference.
